# Water Systems Ontology

A LinkML-authored ontology for collection and stormwater systems that generates the Databricks data model, Unity Catalog metadata and agent context, consumes the OpenSWMM engine catalog and hydrocouple.platform contracts, and gives AI agents a governed vocabulary to reason in.

- [How it fits together](architecture.md) — sources, this repo, Databricks, execution; how a question travels.
- [Knowledge graph](diagrams/knowledge-graph.md) — the entities and their connections.
- [Module map](diagrams/modules.md) and per-module class diagrams.
- [Relations](diagrams/relations.md) — what may connect to what.
